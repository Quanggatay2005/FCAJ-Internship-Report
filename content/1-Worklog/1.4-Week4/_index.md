### Week 4 Objectives:

* Understand data migration, schema conversion, and disaster recovery methods.
* Get familiar with serverless computing (Lambda) and monitoring tools (CloudWatch, Grafana).
* Practice secure access management and system resource organization.

### Week 4 Achievements:

* Understood and capable of setting up data migration workflows (AWS DMS, SCT) and disaster recovery plans (Elastic Disaster Recovery).
* Successfully configured serverless functions using AWS Lambda.
* Gained the ability to deploy system monitoring using CloudWatch and Grafana.
* Learned how to organize resources and manage internal access securely (Systems Manager Session Manager).

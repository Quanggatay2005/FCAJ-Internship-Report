### Week 6 Objectives:

* Understand and configure AWS Reliability through backup services and distributed network management.
* Grasp the concepts of High Availability architectures and shared storage.
* Explore performance optimization using containers, CI/CD pipelines, and databases.

### Tasks to be carried out this week:
| Day | Task                                                                                                                                                                                   | Start Date | Completion Date | Reference Material                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | --------------- | ----------------------------------------- |
| 2,3 | - Learn about Reliability in AWS: <br>&emsp; + Data protection with AWS Backup <br>&emsp; + Network integration with VPC Peering <br>&emsp; + Centralized network management with AWS Transit Gateway | 13/07/2026 | 14/07/2026 | <https://cloudjourney.awsstudygroup.com/> |
| 4,5 | - Learn about Shared Storage mechanisms in Amazon EBS Multi-Attach <br> - Learn about High Availability architectures | 15/07/2026 | 16/07/2026 | <https://cloudjourney.awsstudygroup.com/> |
| 6   | - Learn about Performance in AWS: Docker, ECS, CDK, CodePipeline, DynamoDB | 17/07/2026 | 17/07/2026 | <https://cloudjourney.awsstudygroup.com/> |


### Week 6 Achievements:

* Mastered ensuring system reliability using AWS Backup, connecting VPCs via Peering, and Transit Gateway.
* Understood how to flexibly share storage with EBS Multi-Attach and design fault-tolerant systems (High Availability).
* Learned how to package, automate deployment, and optimize performance with Docker, ECS, CodePipeline, and DynamoDB.

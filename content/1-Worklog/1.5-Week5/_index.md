### Week 5 Objectives:

* Learn how to deploy Infrastructure as Code (IaC) on AWS.
* Get familiar with network traffic monitoring and cost management tools.
* Deep dive into core AWS security mechanisms and services.

### Tasks to be carried out this week:
| Day | Task                                                                                                                                                                                   | Start Date | Completion Date | Reference Material                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | --------------- | ----------------------------------------- |

### Week 5 Achievements:

* Mastered the concepts and usage of Infrastructure as Code (IaC) through CloudFormation and CDK.
* Learned how to manage costs (Cost and Usage Management) and monitor network data flows (VPC Flow Logs).
* Enhanced awareness and practical skills in AWS security with various services: SSO, IAM Permission Boundaries, Security Hub, WAF, KMS, Macie.
* Gained the ability to design AWS systems that comply with safety and information security standards.

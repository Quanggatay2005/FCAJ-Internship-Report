# Event Report

### Purpose of the Event

- Sharing about the journey of participating in FCJ by a group admin
- Introducing the role and responsibilities of a DevOps Engineer.
- Sharing about the culture and work of a Data Analytics Engineer and a Process Engineer.
- A small demo of a URL shortening service applying AWS services.

### List of Speakers

- **Danh Hoang Hieu Nghi** - AI Engineer, AWS Community Builder - AWS Student Builder Group
- **Trong H.Truong** - DevOps Engineer, Endava Vietnam
- **Dat Pham** - Data Analytics Engineer 
- **Cuong Nguyen** - Process Engineer 
- **Dinh Trung Kien** - Lead Developer at startup
- **Nguyen Minh Tho** - Student

### Key Content

#### Sharing about the journey from a student to an AWS Community Builder (Mr. Nghi)
- Started as a student -> joined the FCJ program -> AWS Community Builder
- Received dedicated guidance from the program's mentors
- Overcame many challenges, each providing valuable lessons

#### Role and responsibilities of a DevOps Engineer in a company (Mr. Trong)

- **Prospects of DevOps in the industry**: the salary range of a DevOps Engineer is average in the current IT job market, spread across years of experience
- **What does a DevOps Engineer do?**: the scope of a DevOps Engineer is very broad, depending on the size and requirements of each company.
- **What do students need to do to become a DevOps Engineer?**: Mr. Trong advised everyone to carefully learn the fundamentals first.
    + Intro to programming: linux, networking, programming languages, Git, CI/CD, containers
    + Understand and implement how applications are running
    + Practice anytime, anywhere, whenever learning something new.

#### Sharing from a Data Analytics Engineer about their daily work (Mr. Dat Pham)

- **Daily tasks of a Data Analytics Engineer**: depends on the domain, business model, and supporting departments. For Kalmereo, Mr. Dat will:
    + Build daily, weekly, monthly, and quarterly reports for tracking
    + Design Dashboards
    + Analyze business metrics
    + Coordinate with departments to solve arising problems.
- **Essential skills to survive**:
    + Psychology
    + Forum
    + Auto_graph
    + Lightbulb
- **Career development mindset**: Mr. Dat proposed a linear process to gradually improve personal capabilities.
    + Follower
    + Learner
    + Problem Solver
    + System Thinker
    + Super Star

#### Culture at Multinational Corporations (MNCs) (Mr. Cuong)

- Mr. Cuong introduced the standard recruitment process at MNCs, including:
    + Screening & initial interview
    + Competency test
    + Technical interview
    + Cultural fit
- The life philosophy Mr. Cuong upholds: **being a human -> being a professional -> being a citizen**

#### Developing a URL Shortener using AWS services (Mr. Kien and Tho)
- Introduction to URL Shortener
- Guide on how to build a URL Shortener on AWS: CloudFront, Amazon WAF, Amplify, ECS, ElastiCache 





### What was Learned

- **Mindset shift**: Proactive mindset, willing to learn, and participating in professional activities
- **Solid foundation is a must**: rushing to learn tools doesn't increase survival chances. Conversely, core, foundational knowledge helps you adapt better to technological changes
- **Adapting to the changes of the new era**: in the new era, each person also needs to have the right attitude.

### Experience during the event

Attending the workshop was a very rewarding experience, giving me a comprehensive view of how Data Analytics and DevOps Engineers work. Some highlight experiences:

#### Learning from highly specialized speakers
- Gained a better understanding of the work and real-world problems they have experienced, providing me with more data to decide my future career path.
- Learned how to think about problems, handle them, and propose solutions. Each speaker had a very different approach, giving me multiple perspectives and choices.

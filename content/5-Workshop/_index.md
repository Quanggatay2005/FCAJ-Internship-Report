# Building a Serverless E-commerce Recommendation System on AWS

#### Overview

In this workshop, you will build a complete e-commerce website with a personalized product recommendation system, deployed entirely on AWS using a **serverless** architecture.

What sets this system apart from a typical online store is that every signed-in user sees a different list of recommended products, generated by an **Amazon Personalize** machine learning model based on browsing and purchase behaviour, rather than a fixed ranking by sales volume.

By the end, you will have a system running live on the Internet at close to zero cost when there is no traffic.

#### What you will learn

- Designing a serverless architecture that separates static content delivery from dynamic data flow
- Configuring CloudFront with Origin Access Control to protect an S3 bucket from direct access
- Designing DynamoDB tables around access patterns, using composite keys to avoid full table scans
- Applying the principle of least privilege when creating IAM roles
- Training and deploying a recommendation model with Amazon Personalize
- Setting up alerting with CloudWatch Alarms
- Cleaning up resources properly to avoid unexpected charges

#### AWS services used

| Service | Role in the system |
|---|---|
| Amazon S3 | Stores static frontend files and the training dataset |
| Amazon CloudFront | Delivers the frontend from edge locations, provides HTTPS |
| Amazon API Gateway | Entry point for all API calls |
| AWS Lambda | Runs the business logic |
| Amazon DynamoDB | Stores product, user and order data |
| Amazon Personalize | Trains and serves the recommendation model |
| AWS IAM | Controls permissions between services |
| Amazon CloudWatch | Logging and alerting |

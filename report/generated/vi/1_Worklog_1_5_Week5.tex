\begin{itemize}
\tightlist
\item
  Tìm hiểu cách triển khai hạ tầng dưới dạng mã (Infrastructure as Code

\item
  Đi sâu vào các cơ chế và dịch vụ bảo mật (Security) cốt lõi của AWS.
\end{itemize}

\vspace{0.5em}\noindent\textbf{Kết quả đạt được tuần
5:}\par

\begin{itemize}
\tightlist
\item
  Nắm vững khái niệm và cách sử dụng Infrastructure as Code (IaC) thông
  qua CloudFormation và CDK.
\item
  Biết cách quản lý chi phí (Cost and Usage Management) và theo dõi
  luồng dữ liệu mạng (VPC Flow Logs).
\item
  Nâng cao nhận thức và kỹ năng thực hành về bảo mật trên AWS với hàng
  loạt dịch vụ: SSO, IAM Permission Boundaries, Security Hub, WAF, KMS,
  Macie.
\item
  Có khả năng thiết kế hệ thống AWS tuân thủ các tiêu chuẩn an toàn và
  bảo mật thông tin.
\end{itemize}

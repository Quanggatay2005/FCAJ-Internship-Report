\vspace{0.5em}\noindent\textbf{Role and responsibilities of a DevOps Engineer in a company
(Mr.~Trong)}\par

\begin{itemize}
\tightlist
\item
  \textbf{Prospects of DevOps in the industry}: the salary range of a
  DevOps Engineer is average in the current IT job market, spread across
  years of experience
\item
  \textbf{What does a DevOps Engineer do?}: the scope of a DevOps
  Engineer is very broad, depending on the size and requirements of each
  company.
\item
  \textbf{What do students need to do to become a DevOps Engineer?}:
  Mr.~Trong advised everyone to carefully learn the fundamentals first.

  \begin{itemize}
  \tightlist
  \item
    Intro to programming: linux, networking, programming languages, Git,
    CI/CD, containers
  \item
    Understand and implement how applications are running
  \item
    Practice anytime, anywhere, whenever learning something new.
  \end{itemize}
\end{itemize}

\vspace{0.5em}\noindent\textbf{What was Learned}\par

\begin{itemize}
\tightlist
\item
  \textbf{Mindset shift}: Proactive mindset, willing to learn, and
  participating in professional activities
\item
  \textbf{Solid foundation is a must}: rushing to learn tools doesn't
  increase survival chances. Conversely, core, foundational knowledge
  helps you adapt better to technological changes
\item
  \textbf{Adapting to the changes of the new era}: in the new era, each
  person also needs to have the right attitude.
\end{itemize}

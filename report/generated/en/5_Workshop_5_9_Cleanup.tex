Do this \textbf{immediately after finishing the workshop}. A Personalize
campaign bills per hour it exists; forgetting to delete it means your
bill quietly grows every day.

\vspace{0.5em}\noindent\textbf{Deletion order}\par

Order matters because resources depend on each other. Follow the list
below, starting with the most expensive.

\vspace{0.5em}\noindent\textbf{Step 1. Delete the campaign --- highest
priority}\par

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{aws}\NormalTok{ personalize delete{-}campaign }\AttributeTok{{-}{-}campaign{-}arn} \OperatorTok{\textless{}}\NormalTok{CAMPAIGN{-}ARN}\OperatorTok{\textgreater{}}
\end{Highlighting}
\end{Shaded}

Or in the console: \textbf{Personalize} \(\rightarrow\)
\textbf{Campaigns} \(\rightarrow\) select the campaign \(\rightarrow\)
\textbf{Delete}.

Wait for the status to become \textbf{Delete pending} and then disappear
from the list.

\vspace{0.5em}\noindent\textbf{Step 2. Delete the solution and dataset
group}\par

These must be deleted in this exact order, otherwise you get dependency
errors:

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Delete the solution first}
\ExtensionTok{aws}\NormalTok{ personalize delete{-}solution }\AttributeTok{{-}{-}solution{-}arn} \OperatorTok{\textless{}}\NormalTok{SOLUTION{-}ARN}\OperatorTok{\textgreater{}}

\CommentTok{\# Wait for it to disappear, then delete the dataset}
\ExtensionTok{aws}\NormalTok{ personalize delete{-}dataset }\AttributeTok{{-}{-}dataset{-}arn} \OperatorTok{\textless{}}\NormalTok{DATASET{-}ARN}\OperatorTok{\textgreater{}}

\CommentTok{\# Finally delete the dataset group}
\ExtensionTok{aws}\NormalTok{ personalize delete{-}dataset{-}group }\AttributeTok{{-}{-}dataset{-}group{-}arn} \OperatorTok{\textless{}}\NormalTok{DSG{-}ARN}\OperatorTok{\textgreater{}}
\end{Highlighting}
\end{Shaded}

If the solution has \textbf{automatic retraining} enabled, turn it off
before deleting, otherwise it may kick off a new training run and incur
cost.

\vspace{0.5em}\noindent\textbf{Step 3. Delete the CloudFront
distribution}\par

CloudFront will not delete an enabled distribution, so disable it first.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Open the
  \href{https://console.aws.amazon.com/cloudfront/v4/home}{CloudFront
  console}
\item
  Select the distribution and choose \textbf{Disable}
\item
  Wait roughly 15 minutes for the status to return to \textbf{Deployed}
\item
  Select the distribution again and choose \textbf{Delete}
\end{enumerate}

\vspace{0.5em}\noindent\textbf{Step 4. Delete the S3
buckets}\par

A bucket must be empty before it can be deleted:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{aws}\NormalTok{ s3 rm s3://fcj{-}recsys{-}frontend{-}}\OperatorTok{\textless{}}\NormalTok{your{-}name}\OperatorTok{\textgreater{}}\NormalTok{ {-}{-}recursive}
\ExtensionTok{aws}\NormalTok{ s3 rb s3://fcj{-}recsys{-}frontend{-}}\OperatorTok{\textless{}}\NormalTok{your{-}name}\OperatorTok{\textgreater{}}

\ExtensionTok{aws}\NormalTok{ s3 rm s3://fcj{-}recsys{-}data{-}}\OperatorTok{\textless{}}\NormalTok{your{-}name}\OperatorTok{\textgreater{}}\NormalTok{ {-}{-}recursive}
\ExtensionTok{aws}\NormalTok{ s3 rb s3://fcj{-}recsys{-}data{-}}\OperatorTok{\textless{}}\NormalTok{your{-}name}\OperatorTok{\textgreater{}}
\end{Highlighting}
\end{Shaded}

\vspace{0.5em}\noindent\textbf{Step 5. Delete API Gateway and
Lambda}\par

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{aws}\NormalTok{ apigatewayv2 delete{-}api }\AttributeTok{{-}{-}api{-}id} \OperatorTok{\textless{}}\NormalTok{API{-}ID}\OperatorTok{\textgreater{}}
\ExtensionTok{aws}\NormalTok{ lambda delete{-}function }\AttributeTok{{-}{-}function{-}name}\NormalTok{ fcj{-}recsys{-}api}
\end{Highlighting}
\end{Shaded}

\vspace{0.5em}\noindent\textbf{Step 6. Delete the DynamoDB
tables}\par

\begin{Shaded}
\begin{Highlighting}[]

  \ExtensionTok{aws}\NormalTok{ dynamodb delete{-}table }\AttributeTok{{-}{-}table{-}name} \VariableTok{$T}
\ControlFlowTok{done}
\end{Highlighting}
\end{Shaded}

\vspace{0.5em}\noindent\textbf{Step 7. Delete the IAM role and
alarms}\par

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{aws}\NormalTok{ iam delete{-}role{-}policy }\AttributeTok{{-}{-}role{-}name}\NormalTok{ fcj{-}recsys{-}lambda{-}role }\AttributeTok{{-}{-}policy{-}name}\NormalTok{ fcj{-}recsys{-}lambda{-}policy}
\ExtensionTok{aws}\NormalTok{ iam detach{-}role{-}policy }\AttributeTok{{-}{-}role{-}name}\NormalTok{ fcj{-}recsys{-}lambda{-}role }\DataTypeTok{\textbackslash{}}
  \AttributeTok{{-}{-}policy{-}arn}\NormalTok{ arn:aws:iam::aws:policy/service{-}role/AWSLambdaBasicExecutionRole}
\ExtensionTok{aws}\NormalTok{ iam delete{-}role }\AttributeTok{{-}{-}role{-}name}\NormalTok{ fcj{-}recsys{-}lambda{-}role}

\ExtensionTok{aws}\NormalTok{ cloudwatch delete{-}alarms }\AttributeTok{{-}{-}alarm{-}names}\NormalTok{ fcj{-}lambda{-}errors fcj{-}lambda{-}latency}
\end{Highlighting}
\end{Shaded}

\vspace{0.5em}\noindent\textbf{Step 8. Final sweep}\par

Do not rely on memory. Verify through the Billing console:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Open the \href{https://console.aws.amazon.com/billing/home}{Billing
  console}
\item
  Choose \textbf{Bills} and check whether any service is still accruing
  cost
\item
  Cross-check with
  \href{https://console.aws.amazon.com/resource-groups/}{Resource
  Groups} to find leftovers
\end{enumerate}

Keeping the \textbf{CloudWatch log group} is fine; logs are cheap and
can be useful later. If you want a completely clean account, delete it
from the CloudWatch console too.

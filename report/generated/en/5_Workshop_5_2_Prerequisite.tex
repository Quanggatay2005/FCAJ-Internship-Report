An Amazon Personalize campaign is \textbf{billed per hour it exists},
regardless of how many queries it serves. It is the most expensive
resource in this workshop. Work through it in one sitting and delete the
campaign as soon as you are done. See \href{../5.9-Cleanup/}{Clean up}.

\vspace{0.5em}\noindent\textbf{Cost estimate}\par

If you complete the workshop in a single day and clean up immediately,
the cost stays very low. Most of it falls within the free tier:

\begin{itemize}
\tightlist
\item
  S3, CloudFront, Lambda, API Gateway, on-demand DynamoDB: effectively
  free at this scale
\item
  Personalize: billed for training time and for how long the campaign
  exists
\end{itemize}

\vspace{0.5em}\noindent\textbf{Verify your environment}\par

Open a terminal and run the following to confirm your tooling is ready:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{aws} \AttributeTok{{-}{-}version}
\ExtensionTok{node} \AttributeTok{{-}{-}version}
\ExtensionTok{aws}\NormalTok{ sts get{-}caller{-}identity}
\end{Highlighting}
\end{Shaded}

The last command returns the Account ID and ARN of your current
identity. If it fails, run \texttt{aws\ configure} again.

Set a default region so you do not have to specify it on every command:

\begin{Shaded}
\begin{Highlighting}[]
\BuiltInTok{export} \VariableTok{AWS\_DEFAULT\_REGION}\OperatorTok{=}\NormalTok{ap{-}southeast{-}1}
\end{Highlighting}
\end{Shaded}

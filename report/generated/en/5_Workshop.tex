\vspace{0.5em}\noindent\textbf{Building a Serverless E-commerce Recommendation System on
AWS}\par

\vspace{0.5em}\noindent\textbf{Overview}\par

In this workshop, you will build a complete e-commerce website with a
personalized product recommendation system, deployed entirely on AWS
using a \textbf{serverless} architecture.

What sets this system apart from a typical online store is that every
signed-in user sees a different list of recommended products, generated
by an \textbf{Amazon Personalize} machine learning model based on
browsing and purchase behaviour, rather than a fixed ranking by sales
volume.

By the end, you will have a system running live on the Internet at close
to zero cost when there is no traffic.

\vspace{0.5em}\noindent\textbf{What you will learn}\par

\begin{itemize}
\tightlist
\item
  Designing a serverless architecture that separates static content
  delivery from dynamic data flow
\item
  Configuring CloudFront with Origin Access Control to protect an S3
  bucket from direct access
\item
  Designing DynamoDB tables around access patterns, using composite keys
  to avoid full table scans
\item
  Applying the principle of least privilege when creating IAM roles
\item
  Training and deploying a recommendation model with Amazon Personalize
\item
  Setting up alerting with CloudWatch Alarms
\item
  Cleaning up resources properly to avoid unexpected charges
\end{itemize}
